## FAQ

**Do I need to match the pro's DPI?**  
The config includes the eDPI (effective DPI) value. Use the included converter to match it to your mouse's DPI.

**Will importing overwrite my current settings?**  
Back up your existing config first. The tool includes a backup utility before applying any config.
